# K3 用户指南

安装快捷方式、GUI/TUI 新版本提示及更新/卸载命令见[安装说明](install-packages.zh-Hans.md)。

[English](user-manual.md) | **简体中文** | [繁體中文](user-manual.zh-Hant.md)

准备歌曲、跟着伴奏唱歌，再保存你的录音。本指南以桌面 GUI 为主，括号内保留英文按钮名，
方便对照界面。点击**设置（Settings）**可以切换界面语言。

## 1. 安装并打开 K3

GUI 支持 **Windows x64** 和 **Linux x64/ARM64**。
macOS 和 Windows ARM64 目前仅提供 CLI/TUI，这些平台请参阅
[项目 README](https://github.com/coanor/k3)。

安装 [v0.1.6 正式版](https://github.com/coanor/k3/releases/tag/v0.1.6)：

Windows：打开 PowerShell，粘贴并运行：

```powershell
irm -ErrorAction Stop https://github.com/coanor/k3/releases/download/v0.1.6/get.ps1 | iex
```

Linux：打开终端，粘贴并运行：

```bash
curl -fsSL https://github.com/coanor/k3/releases/download/v0.1.6/install.sh | bash -s -- --version v0.1.6
```

选择**至少有 12 GiB 剩余空间（CUDA 需 24 GiB）**的磁盘，输入一个新目录或空目录，再输入 `y` 确认。
如果找到已有在线安装，安装入口会改为选择原目录并要求确认升级，详见下方升级说明。
安装需要联网，会自动下载程序、Python 和默认分离模型，无需自行准备。
完整安装通常占用 2–10 GiB。安装器的提示使用英文。

Windows 需要 Windows 10/11；Linux 需要 glibc 2.39 或更高版本及图形桌面。
Ubuntu 24.04 请先安装系统运行库：

```bash
sudo apt update && sudo apt install libasound2t64 libfontconfig1 libxkbcommon-x11-0 libegl1 libgl1-mesa-dri
```

安装完成后，在所选安装目录打开 Windows 的 **`k3-gui.exe`** 或 Linux 的 **`k3-gui`**。
请保留整个安装目录，不要只移动其中的程序。

### 升级已有安装

关闭 K3，再粘贴下面的一行命令，将**在线安装版**升级到最新正式版。
即使是没有 `update` 脚本的 v0.1.1 等旧版本，也可以使用。

Windows PowerShell：

```powershell
irm -ErrorAction Stop https://github.com/coanor/k3/releases/latest/download/upgrade.ps1 | iex
```

Linux/macOS：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/coanor/k3/releases/latest/download/upgrade.sh | bash
```

安装和升级入口会查找已有的在线安装：只找到一个时自动选择目录，核对后输入 `y` 确认；
找到多个时从列表中选择；没有找到时手动输入**原来的 K3 安装目录**。
升级入口会校验下载的安装器，并在原目录更新。
完整 CPU/MPS 安装需至少 12 GiB 剩余空间，CUDA 需 24 GiB。现有模型权重的 SHA-256 符合新版要求时会直接复用，
只下载缺失或摘要变化的模型。工程和录音会保留；从旧版升级还会在旁边保留
`.k3-previous-*` 旧安装备份目录，确认升级正常后再考虑清理备份。
通过 `.exe`、`.deb` 或 `.pkg` 安装的版本，请使用系统安装器或包管理器升级。

在线安装成功后会记住位置。Windows 保存在当前用户的
`HKCU\Software\K3\OnlineInstallations` 注册表项中，无需管理员权限；Linux/macOS 保存用户路径记录。
旧版会通过默认目录、当前目录、PATH 或应用快捷方式尝试定位。装在任意自定义目录、
没有这些线索的旧版可能需要手动选择一次。显式传入 `--prefix` / `-InstallDir` 时始终使用指定目录。

## 2. 选择歌曲保存位置

首次启动时，选择一个**工程目录**。K3 会在这里保存准备好的歌曲、歌词和录音。
请选择音频存储空间充足的位置，并与 K3 安装目录分开。新用户可选空目录；
已有工程的用户选择原来的工程目录即可。

点击**齿轮按钮**进入设置，可以更换工程目录、调整音量、默认分离档位和界面语言。
修改自动保存，无需编辑配置文件。下次启动会重新打开上次的工程，保持暂停。

## 3. 加入歌曲

1. 点击**分离歌曲（Separate song）**，再点**选择文件（Choose files）**，选择一首或多首音频。
2. 初次使用保留硬件推荐：CPU、旧显卡或低显存推荐 Fast，较新显卡 6–8 GiB 显存推荐 Balanced，8 GiB 以上推荐 Quality。已有设置会保留，也可在设置中修改档位和模型。
3. 一首新歌点击**创建并分离（Create and separate）**，多首点击**加入队列（Queue selected）**。
4. 等歌曲出现在左侧工程列表，再点击它打开。

在分离页面或设置中选择“自动（优先 GPU）”“仅 CPU”或“仅 GPU”。CPU 模式关闭 GPU 推理；GPU 不可用时仅 GPU 模式会报错，自动模式可回退 CPU。选择会保存，对新任务生效。

处理期间可以继续加歌。进度卡显示当前歌曲和等待队列，百分比表示当前处理阶段的进度。
按 **Esc** 可返回播放页面，后台准备继续；点击进度卡可重新打开。

准备期间可播放或录制其他工程。正在替换分轨的工程暂时不能使用。
**替换分轨（Replace stems）**或**加入队列并替换（Queue & replace）**会用该工程
**已保存的原始音频**重新生成音轨，保留歌词和录音。重新选择一个同名文件不会替换原始音频。

默认模型安装后可离线使用。Kim Vocal 2、Compatible 等可选模型首次使用时可能需要额外下载。
分离结果可能残留少量人声或乐器；可以换个档位后替换分轨，再试听效果。

## 4. 播放和添加歌词

点击播放按钮，再选择音轨：

| 音轨 | 听到的内容 |
| --- | --- |
| **原唱（Original）** | 原始歌曲 |
| **伴奏（Backing）** | 伴奏；Quality 默认保留和声，Fast/Balanced 硬件推荐跳过额外和声分离 |
| **人声（Vocals）** | 分离出的主唱 |
| **录音（Take）** | 所选录音与伴奏混合后的效果 |

拖动进度条可以跳转位置，音量滑块调整音量，升降调控件调整歌曲音高。

需要同步歌词时，点击**查找歌词（Find lyrics）**，输入歌名或歌手，预览结果后点击
**使用此版本（Use this version）**。搜索需要联网；保存前原歌词保持不变，取消不会覆盖歌词。

## 5. 录制自己的演唱

1. 接好耳机和麦克风，在操作系统中选好默认输入、输出设备；K3 使用系统默认设备。
2. 打开已有伴奏的歌曲，在**效果（Effect）**中先选 Clean。
3. 点击圆形**录音（Record）**按钮，伴奏会从头播放，同时录下麦克风声音。
4. 耳机按钮控制实时麦克风监听；听到回声或延迟时可关闭。
5. 点击**停止（Stop）**，等待保存和混音完成，录音会自动保存。
6. 在 **Take** 下拉框选中录音，再切换到**录音（Take）**音轨试听。

每次录制都会保存为独立录音。提前停止时，混音中的伴奏仍会保留到歌曲结束。
录音时关闭 K3，也会先停止并保存，再退出。

更换**效果（Effect）**会重新生成所选录音的混音，原始麦克风录音会保留。
处理完成前，请等待，不要切换录音或重新开始录制。

## 6. 分享或删除录音

分享时，用文件管理器打开工程目录，再打开这首歌的 `takes` 文件夹，
找到文件名带 **`mix`** 的 WAV（`take-…-mix.wav` 或 `mix-….wav`），
试听确认是想分享的录音，再复制到别处发送。
**`take-…-dry.wav`** 是未加效果的原始麦克风录音。请保留工程内的文件，让 K3 继续正常使用。

删除时，在 **Take** 中选中录音，点击旁边的 **⋯**，选择**删除所选录音**。
确认框默认**保留录音（Keep take）**，Enter 或 Esc 都会保留；
明确点击**删除录音（Delete take）**才会删除。其他录音、歌词和歌曲音轨不受影响。

备份时复制**整个工程目录**，即可保留歌曲和录音。更新 K3 时安装到新的空目录，
启动后重新选择原来的工程目录。

## 7. 可选：网易云音乐来源

在**分离歌曲**页面启用实验性网易云音乐来源。点击**扫码登录（QR login）**，
用网易云手机 App 扫码，或选择**导入 Chrome 登录信息（Import Chrome login）**。
搜索歌曲或打开**我喜欢的歌曲（Liked songs）**，勾选后点击**将所选歌曲加入队列（Queue selected songs）**。
只下载账号有权访问的歌曲。

黄色勾表示已入队，绿色勾表示音频已下载；**DOWNLOADED** 不代表分离完成。
准备好的歌曲会出现在工程列表。下载和分离期间可以继续加歌，登录过期时重新登录。
这个实验性来源可能失效，届时可以使用本地音频文件。

## 8. 遇到问题

| 问题 | 可以尝试 |
| --- | --- |
| 安装提示磁盘空间不足 | 换个磁盘或释放空间，安装目录必须是新目录或空目录。 |
| GUI 无法打开 | 检查平台要求；Linux 检查上面的系统运行库，并保留完整安装目录。 |
| 没有声音或录不到麦克风 | 检查系统默认设备和音量；录音前需先准备好伴奏。 |
| 录音时有回声 | 使用耳机，或关闭实时监听。 |
| 找不到歌词 | 在查找歌词时输入更准确的歌名和歌手。 |
| 分离失败 | 检查磁盘空间；需要下载模型时检查网络，再试 Quality 和 Runtime default。 |

仍无法解决时，点击**信息按钮 → About** 查看诊断日志路径。
反馈问题时附上日志和复制的错误文字。Windows 启动失败的弹窗也会显示日志路径。

主界面获得焦点时常用快捷键：**Space** 播放／暂停，**1–4** 切换音轨，
**R** 开始／停止录音，**M** 切换监听，**L** 查找歌词，**Esc** 关闭面板。
