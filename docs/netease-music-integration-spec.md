# 网易云音乐实验性集成规格

## 背景

K3 的媒体库目前只扫描本地音乐，并可选择性调用网易云音乐的免登录网页接口查找歌词。
本功能增加一个默认关闭的网易云音乐来源：用户可以从本机 Chrome 明确导入已登录会话，
也可以扫码登录；登录后可以浏览“我喜欢的音乐”、搜索单曲，并把账号有权访问的音频下载
到本地媒体库。

网易云音乐没有为这一用法提供稳定的公开开发者接口。本功能依赖未公开接口，可能因服务端
变更、账号策略、版权、会员等级或地区限制而失效。它必须保持实验性质，不得默认启用，
也不得把“技术上可以下载”表述为用户拥有额外的内容使用权。

## 目标

- 优先从本机 Chrome 导入网易云音乐登录，并保留终端二维码作为回退方式。
- 登录后浏览当前账号的“我喜欢的音乐”。
- 登录后搜索单曲。
- 下载选中的歌曲，或经二次确认后下载全部喜欢歌曲。
- 自动选择账号当前可用的最高音质，并透明报告实际音质及降级结果。
- 下载结果进入现有本地媒体库，但不自动创建 project 或启动人声分离。
- 将私有协议隔离在可替换的 Rust provider 中，不引入 Node.js 或 Python 服务。

## 非目标

- 不浏览或下载用户创建、收藏的其他歌单。
- 不提供专辑、歌手或歌单搜索。
- 不提供远程在线播放或试听。
- 不自动下载网易云歌词；歌词继续使用 K3 现有流程。
- 不支持多个网易云账号同时登录。
- 不把本地目录严格镜像为远端喜欢列表，取消喜欢不会删除本地文件。
- 不保证未公开接口的长期兼容性。

## 启用与风险确认

媒体库配置增加以下可选字段：

```json
{
  "netease": {
    "enabled": true
  }
}
```

未启用时，TUI 不显示网易云入口，也不发起任何网易云请求。首次进入网易云来源时，TUI
显示一次英文风险提示，说明该来源依赖未公开接口、可能失效，且用户需要确保使用和下载
行为符合账号权限及当地规则。确认状态只保存在本机。

## 登录与凭据

1. 用户把右侧来源面板从 `Local Music` 切换到 `NetEase`。
2. 未登录时按 `c` 才读取本机 Chrome；K3 不在启动、切换来源或风险确认时自动读取浏览器数据。
3. 导入只查询 `music.163.com`，按 Chrome 最近使用的 Profile 顺序逐个验证，只保留
   `MUSIC_U` 和可选的 `__csrf`。无关站点和无关 Cookie 不得复制到 K3。
4. 第一个经网易云账号接口验证成功的 Profile 成为当前会话；无有效 Cookie、系统钥匙串
   不可用、浏览器数据库不可读和服务端暂时失败必须显示不同的英文错误语义。
5. 按 `i` 可改用二维码。TUI 弹窗直接渲染二维码，同时显示过期倒计时以及英文
   `Refresh`、`Import Chrome`、`Cancel` 操作。
6. 二维码登录状态包括等待扫码、等待手机确认、成功、过期和失败。
7. Cookie 失效时，正在下载的队列暂停；用户重新导入 Chrome 会话或扫码成功后从当前
   歌曲继续。
8. `Logout` 删除 K3 的本地凭据副本并清空内存中的远程数据，但不修改 Chrome Cookie，
   也不删除下载文件或下载索引。

每个操作系统用户只保存一个网易云账号。凭据写入操作系统标准 K3 配置目录：

- Linux：`$XDG_CONFIG_HOME/k3/`，未设置时使用 `$HOME/.config/k3/`；
- Windows：`%APPDATA%\k3\`；
- macOS：`~/Library/Application Support/k3/`。

Chrome 导入需要读取浏览器 Cookie 数据库和操作系统钥匙串。macOS 可能显示钥匙串授权
提示；Linux 需要当前桌面会话的 Secret Service 可用；现代 Windows Chrome 的
App-Bound 加密可能要求提升权限，且受设备绑定保护的会话仍可能无法在 K3 中复用。

凭据必须原子写入。Unix 文件权限为 `0600`；Windows 应限制为当前用户可访问。Cookie
不得出现在日志、错误详情、下载索引、媒体库配置或测试夹具中。导入值含控制字符、空白或
分号时必须拒绝，不能直接拼入 HTTP Header。私有配置文件无法抵御已经能够读取当前用户
文件的恶意程序，文档必须明确这一限制。

## 来源面板与选择

现有三栏布局保持不变，右侧来源面板可在 `Local Music` 与 `NetEase` 间切换。所有新增
用户可见文字使用英文。

登录后的网易云来源提供两个视图：

- `Liked Songs`：按服务端顺序分页读取“我喜欢的音乐”；
- `Search`：输入文本并分页显示单曲结果。

每一行至少显示歌名、歌手、专辑、可用状态和服务端报告的最高可用音质。不可下载的歌曲
仍保留在列表中并标明原因。

选择规则：

- `Space`：选择或取消当前歌曲；
- `a`：选择当前已加载页面；
- `A`：拉取并选择全部喜欢歌曲；
- `Enter`：启动下载；
- 下载全部喜欢歌曲前显示总数并再次确认。

搜索结果只支持下载单曲，不支持远程试听。

## 下载与本地文件

下载根目录固定为 `music_root/NetEase/`。目录采用平铺结构，文件名为：

```text
<主歌手>-<歌名>.<扩展名>
```

连字符两侧不留空格。文件名字符必须按目标平台清理；同名冲突时附加网易云歌曲 ID。
多歌手歌曲只把主歌手写入文件名，完整歌手列表仍写入音频标签。

下载文件写入以下标准元数据：

- 歌名；
- 完整歌手列表；
- 专辑；
- 网易云歌曲 ID；
- 封面。

下载索引按网易云歌曲 ID 记录本地路径、实际音质和必要的来源元数据。远程喜欢列表及搜索
结果只保存在内存中，不持久化搜索历史。

下载采用以下规则：

1. 请求账号当前可用的最高音质；不可用时逐级降级并显示实际音质。
2. 已存在同等或更高音质时跳过。
3. 存在更高音质时允许升级。新文件必须先完整下载、验证并原子落盘，成功后才删除旧版本。
4. 不可下载歌曲跳过，并在批次结束时汇总原因。
5. 取消喜欢不会删除本地文件。
6. 临时文件不得被媒体库扫描；异常退出后可以安全清理。
7. 下载结束后自动刷新本地媒体库，新文件由用户按现有流程手动导入和分离。

## 后台任务与失败策略

- 下载队列一次只下载一首歌。
- 下载在后台运行，用户可以继续浏览 TUI。
- 下载任务与现有导入/分离任务互斥，共享一个后台任务通道。
- 有活动任务时退出 K3 必须要求确认；确认后取消队列。
- 中断后重新发起相同选择，依靠歌曲 ID 索引跳过已完成项。
- 超时、限流及服务器 `5xx` 最多自动重试三次，并使用指数退避。
- 版权、会员、地区或不存在等确定性失败不重试。
- Cookie 失效时暂停队列并要求重新登录，而不是丢弃剩余任务。

## 模块与接口

NetEase 应作为深模块放在 `k3-cli` 内：TUI 只需要知道登录状态、分页歌曲列表、选择结果、
下载进度和用户可操作错误。HTTP 请求、未公开协议、Cookie、分页组合、音质协商、重试、
文件名清理、下载索引及原子文件替换隐藏在模块实现中。

外部 HTTP 是测试 seam：生产使用真实 HTTP adapter，自动化测试使用本地 mock adapter。
Chrome Cookie 读取也是测试 seam：生产 adapter 负责跨平台解密，测试只提供合成的
Profile 和 Cookie 名值。不得为了测试而把加密参数、Cookie 细节或单个端点暴露给 TUI。

## 测试策略

CI 不使用真实网易云账号，也不保存真实 Cookie。自动化测试通过 mock adapter 覆盖：

- 配置默认关闭及显式启用；
- 二维码登录状态转换、过期和重新登录；
- Chrome 多 Profile 顺序验证、最小 Cookie 筛选、无有效会话及读取失败；
- 非法 Cookie Header 字符被拒绝，浏览器凭据和测试密钥不进入错误或状态文字；
- 凭据的保存、加载与退出删除；
- 喜欢列表和单曲搜索分页；
- 多选、当前页全选和全部喜欢歌曲确认；
- 最高音质选择与降级报告；
- 文件命名、歌曲 ID 去重和音质升级；
- 临时失败重试、确定性失败跳过及登录失效暂停；
- 下载与导入/分离任务互斥；
- Cookie 不进入日志或用户可见错误。

仓库可以提供开发者显式运行的真实服务冒烟测试入口，但它不得加入默认测试或 CI，也不得
要求把 Cookie 注入 CI。

## 验收标准

1. 未配置 `netease.enabled` 时，现有媒体库行为和界面不变。
2. 启用后，用户可在 TUI 内完成风险确认、从 Chrome 导入或二维码登录，并跨重启恢复会话。
3. 用户可浏览“我喜欢的音乐”、搜索单曲并多选下载。
4. `A` 能选择全部喜欢歌曲，并在下载前显示数量和要求确认。
5. 下载文件按约定命名，包含标准标签和封面，并出现在刷新后的本地媒体库中。
6. 同一歌曲不会重复下载；更高音质升级失败时旧文件保持完整。
7. 不可下载歌曲、音质降级、重试耗尽和登录失效都有明确英文状态或摘要。
8. 只有用户按 `c` 时才读取 Chrome；只复制网易云的必要 Cookie，退出登录后删除 K3
   副本且不修改 Chrome，日志和测试输出不泄漏 Cookie。
9. Linux、Windows 和 macOS 目标保持可编译；默认测试不访问真实网易云服务。
