# K3 使用者指南

安裝捷徑、GUI/TUI 新版本提示及更新/解除安裝命令請參閱[安裝說明](install-packages.md#update-or-uninstall-an-online-installation)。

[English](user-manual.md) | [简体中文](user-manual.zh-Hans.md) | **繁體中文**

準備歌曲、跟著伴奏唱歌，再儲存你的錄音。本指南以桌面 GUI 為主，括號內保留英文按鈕名稱，
方便對照介面。點擊**設置（Settings）**可以切換介面語言。

## 1. 安裝並開啟 K3

GUI 支援 **Windows x64** 和 **Linux x64/ARM64**。
macOS 和 Windows ARM64 目前僅提供 CLI/TUI，這些平台請參閱
[專案 README](https://github.com/coanor/k3)。

安裝 [v0.1.2 正式版](https://github.com/coanor/k3/releases/tag/v0.1.2)：

Windows：開啟 PowerShell，貼上並執行：

```powershell
irm -ErrorAction Stop https://github.com/coanor/k3/releases/download/v0.1.2/get.ps1 | iex
```

Linux：開啟終端機，貼上並執行：

```bash
curl -fsSL https://github.com/coanor/k3/releases/download/v0.1.2/install.sh | bash -s -- --version v0.1.2
```

選擇**至少有 8 GiB 可用空間**的磁碟，輸入新的或空的安裝目錄，再輸入 `y` 確認。
安裝需要連線，會自動下載程式、Python 和預設分離模型，無需自行準備。
完整安裝通常使用 2–4 GiB。安裝程式的提示使用英文。

Windows 需要 Windows 10/11；Linux 需要 glibc 2.39 或更新版本及圖形桌面。
Ubuntu 24.04 請先安裝系統執行階段函式庫：

```bash
sudo apt update && sudo apt install libasound2t64 libfontconfig1 libxkbcommon-x11-0 libegl1 libgl1-mesa-dri
```

安裝完成後，在所選安裝目錄開啟 Windows 的 **`k3-gui.exe`** 或 Linux 的 **`k3-gui`**。
請保留整個安裝目錄，不要只移動其中的程式。

## 2. 選擇歌曲儲存位置

首次啟動時，選擇一個**專案目錄**。K3 會在這裡儲存準備好的歌曲、歌詞和錄音。
請選擇音訊儲存空間充足的位置，並與 K3 安裝目錄分開。新使用者可選空目錄；
已有專案的使用者選擇原來的專案目錄即可。

點擊**齒輪按鈕**進入設定，可以更換專案目錄、調整音量、預設分離模式和介面語言。
變更會自動儲存，無需編輯設定檔。下次啟動會重新開啟上次的專案，保持暫停。

## 3. 加入歌曲

1. 點擊**分離歌曲（Separate song）**，再點**選擇檔案（Choose files）**，選擇一首或多首音訊。
2. 初次使用保留**高質量（Quality）**和**運行環境預設模型（Runtime default）**；處理太慢時可試 Balanced 或 Fast。
3. 一首新歌點擊**創建並分離（Create and separate）**，多首點擊**加入佇列（Queue selected）**。
4. 等歌曲出現在左側專案清單，再點擊它開啟。

處理期間可以繼續加歌。進度卡顯示目前歌曲和等待佇列，百分比表示目前處理階段的進度。
按 **Esc** 可返回播放頁面，背景準備繼續；點擊進度卡可重新開啟。

準備期間可播放或錄製其他專案。正在替換分軌的專案暫時無法使用。
**替換分軌（Replace stems）**或**加入佇列並替換（Queue & replace）**會用該專案
**已儲存的原始音訊**重新產生音軌，保留歌詞和錄音。重新選擇同名檔案不會替換原始音訊。

預設模型安裝後可離線使用。Kim Vocal 2、Compatible 等可選模型首次使用時可能需要額外下載。
分離結果可能殘留少量人聲或樂器；可以換個模式後替換分軌，再試聽效果。

## 4. 播放和加入歌詞

點擊播放按鈕，再選擇音軌：

| 音軌 | 聽到的內容 |
| --- | --- |
| **原唱（Original）** | 原始歌曲 |
| **伴奏（Backing）** | 伴奏，預設保留和聲 |
| **人聲（Vocals）** | 分離出的主唱 |
| **錄音（Take）** | 所選錄音與伴奏混合後的效果 |

拖曳進度條可以跳轉位置，音量滑桿調整音量，升降調控制項調整歌曲音高。

需要同步歌詞時，點擊**查找歌詞（Find lyrics）**，輸入歌名或歌手，預覽結果後點擊
**使用此版本（Use this version）**。搜尋需要連線；儲存前原歌詞保持不變，取消不會覆蓋歌詞。

## 5. 錄製自己的演唱

1. 接好耳機和麥克風，在作業系統中選好預設輸入、輸出裝置；K3 使用系統預設裝置。
2. 開啟已有伴奏的歌曲，在**效果（Effect）**中先選 Clean。
3. 點擊圓形**錄音（Record）**按鈕，伴奏會從頭播放，同時錄下麥克風聲音。
4. 耳機按鈕控制即時麥克風監聽；聽到回聲或延遲時可關閉。
5. 點擊**停止（Stop）**，等待儲存和混音完成，錄音會自動儲存。
6. 在 **Take** 下拉選單選中錄音，再切換到**錄音（Take）**音軌試聽。

每次錄製都會儲存為獨立錄音。提前停止時，混音中的伴奏仍會保留到歌曲結束。
錄音時關閉 K3，也會先停止並儲存，再退出。

更換**效果（Effect）**會重新產生所選錄音的混音，原始麥克風錄音會保留。
處理完成前，請等待，不要切換錄音或重新開始錄製。

## 6. 分享或刪除錄音

分享時，用檔案管理員開啟專案目錄，再開啟這首歌的 `takes` 資料夾，
找到檔案名稱帶 **`mix`** 的 WAV（`take-…-mix.wav` 或 `mix-….wav`），
試聽確認是想分享的錄音，再複製到別處傳送。
**`take-…-dry.wav`** 是未加效果的原始麥克風錄音。請保留專案內的檔案，讓 K3 繼續正常使用。

刪除時，在 **Take** 中選中錄音，點擊旁邊的 **⋯**，選擇**刪除所選錄音**。
確認視窗預設**保留錄音（Keep take）**，Enter 或 Esc 都會保留；
明確點擊**刪除錄音（Delete take）**才會刪除。其他錄音、歌詞和歌曲音軌不受影響。

備份時複製**整個專案目錄**，即可保留歌曲和錄音。更新 K3 時安裝到新的空目錄，
啟動後重新選擇原來的專案目錄。

## 7. 可選：網易雲音樂來源

在**分離歌曲**頁面啟用實驗性網易雲音樂來源。點擊**掃碼登入（QR login）**，
用網易雲手機 App 掃碼，或選擇**匯入 Chrome 登入資訊（Import Chrome login）**。
搜尋歌曲或開啟**我喜歡的歌曲（Liked songs）**，勾選後點擊**將所選歌曲加入佇列（Queue selected songs）**。
只下載帳號有權存取的歌曲。

黃色勾表示已加入佇列，綠色勾表示音訊已下載；**DOWNLOADED** 不代表分離完成。
準備好的歌曲會出現在專案清單。下載和分離期間可以繼續加歌，登入逾期時重新登入。
這個實驗性來源可能失效，屆時可以使用本機音訊檔案。

## 8. 遇到問題

| 問題 | 可以嘗試 |
| --- | --- |
| 安裝提示磁碟空間不足 | 換個磁碟或釋放空間，安裝目錄必須是新的或空的目錄。 |
| GUI 無法開啟 | 檢查平台要求；Linux 檢查上面的系統函式庫，並保留完整安裝目錄。 |
| 沒有聲音或錄不到麥克風 | 檢查系統預設裝置和音量；錄音前需先準備好伴奏。 |
| 錄音時有回聲 | 使用耳機，或關閉即時監聽。 |
| 找不到歌詞 | 在尋找歌詞時輸入更準確的歌名和歌手。 |
| 分離失敗 | 檢查磁碟空間；需要下載模型時檢查網路，再試 Quality 和 Runtime default。 |

仍無法解決時，點擊**資訊按鈕 → About** 查看診斷日誌路徑。
回報問題時附上日誌和複製的錯誤文字。Windows 啟動失敗的對話框也會顯示日誌路徑。

主介面取得焦點時常用快捷鍵：**Space** 播放／暫停，**1–4** 切換音軌，
**R** 開始／停止錄音，**M** 切換監聽，**L** 尋找歌詞，**Esc** 關閉面板。
